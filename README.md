# ASLCOMPANY Group — Website starter

Bilingual (English/Portuguese) React + TypeScript + Vite prototype.

## Run locally
```bash
npm install
npm run dev
```

## Publish
1. Create a public GitHub repository and push these files to its `main` branch.
2. Keep the repository name `aslcompany-website` (the Vite base path is configured for it).
3. In repository Settings > Pages, choose **GitHub Actions** as the source.
4. Push to `main` to deploy.
5. After reviewing the deployed site, configure your custom domain in Pages settings and update DNS records at your domain registrar. Do not cancel Wix until the new site and DNS are confirmed working.

## Before launch
- Replace the text-only placeholder brand with the approved ASLCOMPANY logo.
- Verify and update the contact email in `src/main.tsx`.
- Review all service offerings for delivery readiness and validate claims.
- Add legal/privacy disclosures, analytics consent if needed, real contact form provider, and multilingual SEO metadata.
- The Volkswagen example is clearly attributed to the founder's employment experience, not to an ASLCOMPANY client contract.
- No Microsoft Partner/MVP status is claimed.
